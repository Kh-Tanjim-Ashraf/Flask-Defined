# Flask App - Template & Static Files Render utilizing the Jinja Template

This is a simple Flask application demonstrating how to render HTML & CSS files through a Flask server.

Moreover, here I have practiced the _Template Inheritance_ concept by utilizing the **Jinja** template. It's quite similar to Django's template engine, thus it's very intuitive to work with **Flask's Jinja Template**.

## How to Setup

1. Create a Python virtual environment.
   > python -m venv env
2. Activate the virtual environment (_using Bash terminal_).
   > source env/Scripts/activate
3. Install the required dependecies of the project using the `pip` command.
   > pip install -r requirements.txt
4. Spin up the Flask server.
   > python app.py

<small>Note: Since it's running on a development server, we can access the web server at http://localhost:5000 from the browser.</small>
